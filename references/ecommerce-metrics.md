# 电商数据分析方法论 · E-commerce Metrics

本文件供 `qianjin-data-analysis` 在用户数据 / 电商数据类型时调用。聚焦"把 GMV 拆到能动手的颗粒度"。

---

## 一、核心指标口径

| 指标 | 定义 | 公式 / 备注 |
|------|------|------------|
| GMV | 成交总额 | Σ 订单金额（含未支付依口径） |
| 订单量 | 成功订单数 | 去重 order_id |
| 客单价 AOV | 单均消费 | GMV / 订单量 |
| 转化率 CVR | 下单转化 | 下单数 / 访客数（或加购→支付） |
| 复购率 | 多次购买占比 | 购买≥2次用户数 / 总购买用户数（按周期） |
| 连带率 | 客单件数 | 销售件数 / 订单数 |
| 品类集中度 CRn | 前 n 品类占比 | Σ Top n 品类 GMV / 总 GMV |

---

## 二、GMV 拆解模型（定位瓶颈）

GMV = 流量 × 转化率 × 客单价 × 复购系数

逐层对比，定位哪一层拖累增长：
- 流量够但转化低 → 落地页/价格/信任问题
- 转化高但客单低 → 组合销售、满减门槛
- 一次性买卖 → 复购机制（会员、订阅、召回）

拆解示例表（每期数值 + 环比）：

```
指标        本期    上期    环比    结论
流量        120k    100k   +20%   增长健康
转化率      2.1%    3.0%   -30%   ⚠ 主瓶颈
客单价      158     150    +5%    平稳
复购率      18%     22%    -4pp   需召回
```

## 三、转化漏斗

标准电商漏斗：
曝光 → 点击 → 加购 → 下单 → 支付

计算每层转化率与流失率，找出"最大跳变"层：

```
环节      人数    环节转化   累计转化
曝光      100000  -        100%
点击      12000   12.0%     12.0%
加购      3000    25.0%     3.0%
下单      1200    40.0%     1.2%
支付      1000    83.3%     1.0%
```

解读：若"加购→下单"骤降，多为价格/库存/决策犹豫；"支付"流失多为支付体验/风控。

> 若要看**用户全生命周期**（含留存/收入/推荐），升级为 **AARRR 海盗模型**，见 `references/conversion-models.md`：电商漏斗 ≈ AARRR 的"获取→激活（首购）"段，AARRR 再向后延伸到留存/收入/推荐。

## 四、复购与品类结构

- **复购率**按 7/30/90 天分别看，识别召回窗口
- **品类集中度 CR5**：过高（>70%）说明抗风险弱；过低说明无爆品
- **连带率**：低则推组合装、凑单、关联推荐
- **价格带分布**：看 GMV 主要由哪个价格带贡献，避免"假繁荣"

---

## 五、异常与专题

- **突降排查**：先排除数据口径（断档/重复计入），再看是否有活动结束、竞品、负面舆情
- **爆品归因**：销量突增 = 自然流量 / 投放 / 达人 / 平台活动，逐一拆解
- **渠道对比**：各渠道 CVR、AOV、复购差异，决定预算分配

输出时，每个发现配"数字 + 对比基准 + 可能原因 + 建议动作"。
